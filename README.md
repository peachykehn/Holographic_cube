# Holographic_cube
45 degree angled etched glass can make a pseudo-holographic effect. The video is playing on a screen below the cube, and there is a piece of privacy screen so you don't see two images. It is powered by an esp32 and a cheap yellow display (literally called "cheap yellow display").
